# Project: DinoPrehistoric

This project is a modern, responsive static website dedicated to dinosaurs, paleontology, evolutionary biology, and prehistoric Earth history.

## Pages

The website consists of the following modern HTML5 pages:

- **index.html**: The main landing portal featuring deep-time hero stats, major dinosaur clades, scientific classification hierarchy, and interactive exhibit previews.
- **history.html**: Detailed evolutionary timeline covering the Permian-Triassic extinction, Triassic/Jurassic/Cretaceous epochs, paleobiogeography (Pangaea breakup), and pelvic classification (Saurischia vs. Ornithischia).
- **about.html**: Historical narrative detailing the dawn of paleontology, William Buckland's *Megalosaurus*, Sir Richard Owen coining *Dinosauria* in 1842, and modern avian theropod connections.
- **photo.html**: Responsive photo gallery with category filter buttons (Theropods, Sauropods, Armored, Fossils) and full-screen image lightbox viewer.
- **photo2018.html**: Complete 2018 archive collection featuring 50 dinosaur illustration plates with real-time live search and lightbox viewing.
- **video.html**: Curated documentary video library featuring themed thumbnail cards, category filter tabs, live title search, and an interactive embedded modal video player.
- **resources.html**: Paleontology academic resource hub with downloadable field guide previews, an in-browser Web Audio bio-resonance sound synthesizer (T-Rex infrasound, raptor calls, crest resonance), and links to authoritative global databases (PBDB, NHM London, Smithsonian).
- **contact.html**: Interactive contact portal with validated inquiry form, visitor hours, Discovery Center address, framed map display, and a collapsible FAQ accordion.
- **sitemap.html**: Categorized visual site directory mapping all core portals, media vaults, research tools, and visitor services.

## Technologies & Design System

- **HTML5**: Clean semantic structure with accessibility attributes (`aria-current`, `role`, `tabindex`).
- **CSS3 / Bootstrap 5.3**: Modern prehistoric museum palette (`--primary-teal`, `--accent-orange`), glassmorphic panels, elevated card systems, and mobile-first responsive grids.
- **Typography**: Google Fonts (*Cinzel* for majestic display titles, *Plus Jakarta Sans* for readable body text).
- **Font Awesome 6.4 & Animate.css**: Scalable iconography and subtle entrance animations.
- **JavaScript (ES6+)**:
  - Smooth scroll & floating back-to-top button.
  - Universal full-screen modal image lightbox.
  - Responsive 16:9 modal video player with automatic pause on close.
  - Interactive multi-category gallery filters and live search inputs.
  - Web Audio API bio-acoustic sound synthesizer for dinosaur vocalizations.
  - Form validation with asynchronous feedback.

- `Images/Big Size/`: Large landscape and period dinosaur visual plates.
